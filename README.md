# 🎬 Film Vault

[![Repository URL](https://img.shields.io/badge/GitHub-Repo-blue?style=flat&logo=github)](https://github.com/Coder240807/film-vault)
> **Project URL**: [https://github.com/Coder240807/film-vault](https://github.com/Coder240807/film-vault)

Film Vault is a modern movie exploration application built using **React**, **Vite**, and **Tailwind CSS**, powered by **TMDB (The Movie Database) API**. It allows users to discover trending movies, search for their favorite titles, filter by genres, manage a personalized watchlist, and view detailed information like ratings and release dates.

---

## ✨ Features

- 🔍 **Real-Time Movie Search**: Instantly find movies by title with dynamic API calls.
- 🔥 **Trending & Top Rated**: Explore trending movies, top-rated titles, and upcoming releases.
- 📌 **Personal Watchlist**: Add movies to your personal watchlist to keep track of films you want to view.
- 🏷️ **Genre Filtering & Sorting**: Filter films by genres and sort by popularity, rating, or release date.
- 📱 **Responsive Design**: Modern, mobile-first dark-mode UI styled using Tailwind CSS.
- ⚡ **Fast & Lightweight**: Built with Vite for instant server start and fast build times.

---

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **API**: [TMDB (The Movie Database) API](https://www.themoviedb.org/documentation/api)

## 🚀 Getting Started

Follow these steps to set up and run the project on your local machine.

### Prerequisites

Ensure you have installed:
- [Node.js](https://nodejs.org/) (v16.x or higher)
- `npm` or `yarn`
- A free **TMDB API Key** (Get one at [TMDB API](https://www.themoviedb.org/settings/api))

### Environment Setup

Create a `.env` file in the root directory of your project and add your TMDB API Key:

```env
VITE_TMDB_API_KEY=your_tmdb_api_key_here
```

1. Clone the repository
git clone [https://github.com/Coder240807/film-vault.git](https://github.com/Coder240807/film-vault.git)
cd film-vault

2. Install dependencies
npm install

3. Start the Development Server
npm run dev

Open http://localhost:5173 in your browser to view the application.
